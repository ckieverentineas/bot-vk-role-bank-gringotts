# Gringotts Bank VK Role Bot

## О проекте

VK-бот банка Гринготтс для сообщества "Хогвартс Онлайн". Бот работает в личных сообщениях сообщества и превращает банковскую часть ролевой в управляемую систему: регистрирует клиентов, выпускает им карточки, ведет счета в галлеонах и магическом опыте, обслуживает покупки, артефакты, услуги и хранилище, а также дает администраторам инструменты для начислений, списаний, уведомлений и контроля базы.

Проект заточен под живую ролевую экономику: пользователь видит меню и интерактивные кнопки, администратор получает быстрые операции по UID, а важные действия уходят в служебный чат как лог. Данные хранятся в SQLite через Prisma, изображения карточек и интерфейсов собираются на лету, а отдельный `/ping` endpoint помогает проверять, что процесс бота жив.

## Что умеет

- регистрирует новых пользователей и создает банковские карточки;
- хранит VK ID, UID, имя, положение, специализацию, уровень, галлеоны и магический опыт;
- генерирует изображение банковской карты с номером, именем и датой выпуска;
- показывает главное меню с карточкой, магазином, услугами, артефактами, статистикой, рейтингом и хранилищем;
- поддерживает приватный режим отображения баланса;
- ведет операции начисления и списания галлеонов и магического опыта;
- позволяет администраторам массово начислять и списывать ресурсы;
- отправляет пользователям личные уведомления о банковских операциях;
- ведет служебные логи в отдельный VK-чат;
- управляет ролями пользователей и root/admin-доступом;
- поддерживает магазин, категории товаров, покупки и выдачу предметов;
- поддерживает артефакты, их выдачу, удаление и просмотр;
- обслуживает конвертацию ресурсов и другие банковские услуги;
- ведет хранилище предметов пользователя;
- начисляет достижения через analyzer-модуль;
- поднимает простой health endpoint `/ping` на локальном Express-сервере.

## Подготовка

Установите зависимости:

```bash
npm install
```

Создайте `.env` в корне проекта:

```bash
cp .env.example .env
```

```env
DATABASE_URL="file:./dev.db"
token="vk_group_token"
root="123456789"
chat_id="2000000001"
group_id="123456789"
```

Переменные:

- `DATABASE_URL` - путь к SQLite базе Prisma. При `file:./dev.db` база лежит в `prisma/dev.db`.
- `token` - токен сообщества VK.
- `root` - VK ID главного администратора.
- `chat_id` - ID беседы для логов.
- `group_id` - запасной ID группы VK для Long Poll и удаления сообщений в беседах. При старте бот пытается определить ID группы по токену автоматически; значение из `.env` используется как fallback.

## База данных

Сгенерировать Prisma Client:

```bash
npm run generate
```

Применить миграции в разработке:

```bash
npx prisma migrate dev
```

Применить миграции на сервере:

```bash
npx prisma migrate deploy
```

Важный нюанс: `User.idvk` и `BlackBox.idvk` хранятся как `BigInt`, чтобы поддерживать новые длинные VK ID. Перед передачей в VK API значения приводятся к обычному числу через `To_Vk_Id(...)`.

Разработка:


```text
http://localhost:3003/ping
```

## Скрипты

- `npm run generate` - генерирует Prisma Client.
- `npm run build` - генерирует Prisma Client, очищает `build` и компилирует TypeScript.
- `npm start` - собирает проект и запускает `build/index.js`.
- `npm run dev` - запускает бота через `ts-node-dev`.
- `npm run pm2` - команда для запуска TypeScript-версии через `ts-node-dev` под процессным менеджером.

В корне также есть Windows-батники:

- `init.bat` - выполняет `npm i`.
- `db.bat` - запускает `prisma migrate dev --name init` и `prisma generate`.
- `start.bat` - запускает `npm run dev`.

## Проверка перед деплоем

```bash
npm run build
npx prisma migrate status
```

Если `migrate status` показывает pending migration, примените ее через `npx prisma migrate deploy` на нужной базе.

## Структура

- `src/index.ts` - точка входа, VK Long Poll, регистрация роутов.
- `src/api.ts` - Express endpoint `/ping`.
- `src/engine/player.ts` - основные пользовательские и админские команды.
- `src/engine/events` - обработчики меню, магазина, услуг, информации и хранилища.
- `src/engine/core` - общие helper-функции и генерация изображений.
- `prisma/schema.prisma` - схема базы данных.
- `prisma/migrations` - миграции Prisma.
